# 网站阶段性开发记录（2026-07-12）

## 1. 本阶段目标

- 完成“舞台风 + 滑稽反差”主交互页面的核心功能联调。
- 补齐卡牌内容、解锁机制、音效和标题页过场。
- 为后续发布做入口收敛：将 `index.html` 统一导向当前主页面。

## 2. 本阶段已完成内容

### 2.1 主界面与交互

- 左侧菜单圆弧滚动、中心卡牌切换、标题/卡牌随机轻微抖动。
- 唱片区播放/暂停/下一首 + 淡入淡出 + 自动播完切歌。
- 背景漂浮黄瓜捕获、货币收集、顶部组件联动。
- 大黄瓜顶飞搜索栏、黄瓜爆发特效、一次性触发约束。
- 舞台幕布序列帧开场与首次点击联动开场音乐。

### 2.2 卡牌业务内容

- 欢迎光临：两行标题 + 说明文案。
- 自制谱面：下载入口 + 谱面列表长文本。
- 神秘小工具：三个压缩包下载入口。
- 私密内容：锁图 + 暗滤镜 + 密码 `000000` 解锁。
- 关于我：三行介绍 + B 站跳转链接。
- 与睦头尬聊：解锁后出现，绿色聊天气泡窗口（无头像）。

### 2.3 解锁剧情与过场

- 与睦头尬聊默认隐藏，需通过特殊黄瓜剧情解锁。
- 特殊黄瓜位于最高层，点击后向中心聚变并触发白屏转场。
- 新增“正经风标题页”：动态渐变、绿细线、粒子效果。
- 点击标题页触发圆形极速蒙版揭露主界面（替代碎片切屏）。

### 2.4 音效系统

- 已建立统一音效播放函数并按交互场景绑定：
  - 卡牌换牌、换碟、钢管、神圣、通用点击音效。

## 3. 页面入口与发布侧配置（本阶段）

- `index.html` 已改为入口跳转页，自动导向 `./prototype-left-menu.html`。
- 这样在 GitHub Pages 访问仓库根路径时，会直接进入当前主页面。

## 4. 当前注意事项

- 聊天模型调用已支持后端代理路径 `/api/chat`。
- 若仅部署静态 GitHub Pages（无后端），聊天会退化为前端兜底回复。
- 生产环境建议使用服务端代理并通过环境变量存储 API Key，避免前端泄露。
